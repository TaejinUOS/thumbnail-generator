# LoL 썸네일 생성기

리그 오브 레전드 풀영상용 1280×720 PNG 썸네일을 만드는 로컬 도구입니다.

## 실행

Node.js 22 이상이 필요합니다. 별도 패키지 설치는 필요 없습니다.

1. `background-images` 폴더에 배경 사진을 넣습니다. JPG, JPEG, PNG, WEBP, AVIF, GIF를 지원합니다. 하위 폴더는 읽지 않습니다.
   배경 사진은 이 PC에만 보관하며 Git 저장소에는 포함되지 않습니다.
2. 바탕화면의 **LoL 썸네일 스튜디오** 바로가기 또는 `start.bat`을 더블클릭합니다. 서버가 백그라운드에서 시작되고 브라우저가 자동으로 열립니다. 개발 중에는 이 폴더의 터미널에서 `npm start`를 실행할 수도 있습니다.
3. 배경, 티어, 챔피언을 선택한 다음 **PNG 다운로드**를 누릅니다.

배경 선택 옆 **🎲 랜덤** 버튼을 누르면 현재 이미지와 다른 배경이 무작위로 선택됩니다.

배경을 추가하거나 바꿨다면 생성기 안의 **새로고침**을 누르세요. 바로가기로 시작한 서버는 브라우저를 닫아도 계속 실행되며 PC를 재시작하면 종료됩니다. `npm start`로 실행했다면 해당 창에서 `Ctrl+C`로 종료합니다. 기본 포트가 다른 프로그램에 사용 중이면 PowerShell에서 `$env:PORT=3001; npm start`로 다른 포트를 지정할 수 있습니다.

## 썸네일 구성

- 좌측 상단: 실제 티어 휘장과 한글 티어명. 아이언~다이아몬드는 로마 숫자 I, II, III, IV 단계입니다.
- 마스터, 그랜드마스터, 챌린저: 0–99 LP부터 9,900–9,999 LP까지 100점 구간을 선택합니다. 게임 계정의 실제 승급 조건을 판정하는 도구는 아닙니다.
- 우측 상단: 다운로드 시점의 컴퓨터 현지 날짜 (`YYYY.MM.DD`).
- 좌측 하단: Me 챔피언 아이콘 최대 3개.
- 우측 하단: 상대 챔피언 아이콘 최대 3개.
- 챔피언 선택 화면에서 사용하는 정사각형 기본 초상화를 사용합니다. 빈 슬롯은 표시하지 않으며 같은 쪽에서 중복 선택할 수 없습니다.
- 각 챔피언 칸에서 한글 이름, 영문 ID, 초성으로 검색할 수 있습니다. 예: `리신`, `Ahri`, `ㅌㅇㅅㅌㄷ`. 검색 결과는 클릭하거나 방향키와 Enter로 선택하고, × 버튼으로 선택을 해제합니다. Escape 또는 칸 밖 클릭은 검색을 취소합니다.
- 배경은 비율을 유지하여 화면을 채웁니다. 잘리는 부분은 가로·세로 위치 슬라이더로 조절합니다. GIF는 정지 이미지로 저장됩니다.
- 배경과 설정은 현재 브라우저에 기억됩니다. 이미지가 없거나 읽기에 실패하면 다운로드를 차단합니다.

## 중앙 문구

중앙 문구 입력 칸에 최대 100자를 입력할 수 있습니다. SB 어그로체 Bold를 사용하며 Enter로 줄을 나눌 수 있습니다. 글자 크기(24–160 px), 화이트·검정 글자색, 그림자 및 검정 배경을 조절할 수 있습니다. 검정 배경은 문구 뒤에만 표시되며, 검정 글자를 함께 선택하면 가는 흰 테두리로 글자를 구분합니다. 긴 문구는 모서리 정보와 겹치지 않도록 중앙 영역에 맞춰 줄바꿈·축소하고 실제 표시 크기를 안내합니다. 문구를 비우면 표시되지 않습니다.

폰트는 PC에 설치되어 있던 SB 어그로체 Bold 원본을 `public/assets/fonts/SBAggroB.ttf`에 포함했습니다. 별도 설치나 인터넷 연결 없이 미리보기와 PNG에 같은 폰트를 사용합니다. 출처는 해당 폴더의 `NOTICE.txt`에 기록했습니다.

## 챔피언·휘장 업데이트

공식 이미지는 `public/assets`에 저장되어 있어 평소에는 인터넷 연결 없이 사용할 수 있습니다. 최신 챔피언이 추가되면 인터넷이 연결된 상태에서 실행하세요.

```powershell
npm run assets
```

Riot Data Dragon의 최신 버전에서 한국어 챔피언 목록과 기본 아이콘을 내려받고, Riot 공식 티어 휘장을 함께 준비합니다. API 키는 필요 없습니다. 완료 후 브라우저 페이지를 새로고침하세요.

출처: [Riot Games Data Dragon 및 Ranked Emblems](https://developer.riotgames.com/docs/lol). 게임 이미지와 상표의 권리는 Riot Games에 있습니다. Riot Games가 제작하거나 보증한 도구가 아닙니다.

## 검증

`npm test`는 배경 목록 조회, 정적 파일 접근 제한, 티어 표기 및 배경 크롭 계산을 검증합니다.
